# 두근AI V2

완전 무료 정적 AI 동반자 웹앱입니다.

## 현재 기능
- 하은 / 서준 / 유리 실사풍 가상 성인 AI 캐릭터
- Demo AI 2.0 대화 엔진
- 캐릭터별 성격과 말투
- 사용자 감정 및 대화 의도 분류
- 취향 / 취미 / 관심사 / 일부 프로필 기억
- 관계 점수와 단계 변화
- 카페 / 도시 야경 / 공원 산책 데이트 장면
- 한국어 브라우저 음성 입력(SpeechRecognition 지원 환경)
- 한국어 브라우저 TTS
- localStorage 기반 대화·기억 저장
- 실제 사람이 아닌 AI 캐릭터임을 상시 표시
- 외부 API 키나 유료 서버 불필요
